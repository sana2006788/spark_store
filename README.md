# FreshHarvest & Spark E-Commerce (Fruits, Vegetables, Grains & Quick-Commerce ERP)

## How to Run Locally
1. Extract this ZIP archive.
2. Double-click `index.html` to open it directly in Google Chrome, Microsoft Edge, or any modern browser (no `npm install` or build step required).
3. Or serve via VS Code Live Server / Python: `python -m http.server 8080` and visit `http://localhost:8080`.

## Key Features Included
- **7-Step Sequential Checkout Flow:** Login -> Retail Store -> Wholesale 50% Bulk Mandi -> Customer Details -> Payment (UPI/Card/COD) -> Order Review -> Confirmation.
- **Fruits, Vegetables & Grains Catalog:** Includes Ratnagiri Alphonso Mangoes, Himachal Royal Gala Apples, Yelakki Bananas, Organic Country Tomatoes, Ooty Hill Potatoes, Hydroponic Baby Spinach, 24-Month Aged Basmati Rice, MP Sharbati Wheat, and Unpolished Pulses.
- **Interactive Product Quick-View Modal:** Multi-angle gallery with 1.65x zoom, storage bin/silo telemetry, specifications, customer reviews, and automatic 50% wholesale threshold calculator.
- **Admin Agro-Storage & Inventory ERP:** Switch to Admin mode in the top bar to monitor Cold-Storage Bins, Moisture-Sealed Dry Grain Silos, restock inventory, and register new harvest batches.
